# QR Code Generator Frontend

A modern, Web 3.0 inspired QR code generator built with React, TypeScript, and Tailwind CSS.

## Features

- 🎨 **Web 3.0 Aesthetics**: Glassmorphism, neon gradients, and smooth animations
- ⚡ **Real-time Generation**: Instant QR code preview as you type
- 🎯 **Customization**: Size, colors, error correction levels, and margins
- 📱 **Responsive Design**: Perfect on all devices
- 🌙 **Dark/Light Mode**: Seamless theme switching
- 📥 **Multiple Formats**: Download as PNG, JPEG, or SVG
- 🔗 **Shareable Links**: Get permanent links to your QR codes
- ✨ **Smooth Animations**: Powered by Framer Motion

## Tech Stack

- **Framework**: React 18 with TypeScript
- **Styling**: Tailwind CSS with custom Web 3.0 theme
- **Animations**: Framer Motion
- **QR Generation**: qrcode.react
- **HTTP Client**: Axios
- **Notifications**: React Hot Toast
- **State Management**: React Context
- **Build Tool**: Create React App
